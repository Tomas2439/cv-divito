# CV Online — Francisco Di Vito

CV interactivo estilo portfolio, de una sola página (single file), con diseño oscuro tipo "commit-log" pensado para un perfil en desarrollo de software con background técnico/mecánico.

🔗 **Ver online:** _(Tomas2439.github.io/cv-divito/)_

---

## ✨ Características

- Diseño responsivo (mobile, tablet, desktop) con menú hamburguesa en mobile.
- Sección **Hero** con nombre, perfil profesional, foto y botones de acción (Descargar CV / LinkedIn).
- **Experiencia profesional** en formato línea de tiempo (estilo log de commits).
- Bloque de **Educación, Habilidades e Idiomas** en grilla.
- Sección de **Contacto** con tarjeta y botones (WhatsApp, Email, LinkedIn, GitHub, Instagram).
- Email protegido contra scraping (se arma vía JavaScript en el click, no queda expuesto en el HTML).
- Botón "Descargar CV" que enlaza al PDF real del currículum.
- Meta tags de SEO y Open Graph para compartir el link con vista previa (WhatsApp, LinkedIn, etc.).

---

## 🛠️ Tecnologías

- **HTML5**
- **CSS3** (Grid, Flexbox, variables CSS, animaciones simples)
- **JavaScript vanilla** (sin frameworks ni dependencias)
- Tipografías vía Google Fonts: `Space Grotesk`, `Inter`, `JetBrains Mono`

No requiere build ni instalación de paquetes — es un único archivo `.html` autocontenido.
